BlendShape Clip Fixer - はじめて使う時の流れ
=============================================

事前に確認すること
------------------
- VCC / VPM で `BlendShape Clip Fixer` を導入済み
- 修正したい `AnimatorController` がある
- 必要に応じて対象アバターと `SkinnedMeshRenderer` を確認できる

最短の使い方
------------
1. Unity メニューの `Tools/Sebanne/BlendShape Clip Fixer` を開きます
2. `Source Controller` に修正したい `AnimatorController` を入れます
3. 必要に応じて `Target Avatar Root` と `Target SkinnedMeshRenderer` を入れます
4. `Scan Controller` を押して、missing 名や path mismatch を確認します
5. 必要なら `Missing / Replace Map` を調整します
6. 問題がなければ `Generate Fixed Assets` を押して修正版 asset を生成します

大事なポイント
--------------
- まずスキャン結果を確認してから生成してください
- 元 asset は直接変更されません
- 対象 `SkinnedMeshRenderer` が未設定だと、一部の判定や置換候補確認が使えません

生成先の目安
------------
既定では次の場所に出力されます。

Assets/BlendshapeClipFixer_Output/<ControllerName>_Fixed/

困った時
--------
- 判定結果や置換候補が不足する時は、対象 `SkinnedMeshRenderer` の設定を見直してください
- 詳しい使い方や説明は repo の `README.md` を参照してください
